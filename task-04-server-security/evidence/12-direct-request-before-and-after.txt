1. THE DIRECT BYPASS ATTACK REQUEST
--------------------------------------------------------------------------------
Command:
curl.exe -i -X POST http://localhost:3000/api/bookings \
  -H "Content-Type: application/json" \
  --data-binary "@scratch/attack_payload.json"

Raw JSON Payload:
{
  "clientName": "X",
  "phone": "000",
  "eventDate": "2020-01-01",
  "guestCount": -50,
  "organizationType": "MaliciousBot"
}

Attacker Intention:
Bypass browser UI validation completely by issuing a direct HTTP POST request with single-character names, invalid phone numbers, dates four years in the past, and negative guest counts.
