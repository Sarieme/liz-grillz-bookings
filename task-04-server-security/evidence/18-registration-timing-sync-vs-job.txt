ARCHITECTURAL VERDICT:
Synchronous email delivery holds the client's HTTP connection hostage while the server establishes a TCP connection, performs TLS negotiation, and transmits SMTP commands. If the SMTP provider experiences transient network jitter or rate limits, the user's browser hangs and may timeout. In contrast, enqueuing email delivery to a background worker returns immediately once the PostgreSQL record and bcrypt hash are persisted, delivering a snappy, resilient experience for event organizers.
