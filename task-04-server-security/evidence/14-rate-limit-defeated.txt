4. ARCHITECTURAL TAKEAWAY
--------------------------------------------------------------------------------
IP-only rate limiting was bypassed instantly by rotating the origin IP address.
To secure production authentication, rate limiting must be keyed on composite identifiers (such as IP + normalized email) and distributed across Redis counters rather than isolated process memory.
