Design System Rule: Primitives vs. Color Roles

Color Roles (e.g. --color-primary, --color-surface) are the only tokens used on UI components. Primitives (e.g. --color-primitive-primary-40) define foundational math/hex scales and are referenced internally via var(). This keeps UI styling semantic and themeable.
